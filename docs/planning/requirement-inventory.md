# REQUIREMENT INVENTORY: SOLAR INSTALLATION MANAGEMENT SYSTEM
**Single Source of Truth Reference:** `SOLAR_MANAGEMENT_SYSTEM.md`  
**Architecture Model:** Modular Monolith (Node.js/Express + PostgreSQL + React/Vite/Tailwind CSS)  
**Document Version:** 1.0.0  
**Status:** Approved for Implementation Planning  

---

## 1. System Scope & Classification Overview
The Solar Installation Management System serves SunPower Solutions (handling ~40 rooftop solar projects/month, residential and small commercial, 1 kW to 5 kW On-Grid and Off-Grid configurations, with a 15-technician field workforce, warehouse, sales, finance, support, and executive management).

### Classification Taxonomy:
- **[M] Mandatory:** Absolute requirement for operational integrity, legal compliance, or contract delivery.
- **[O] Optional / Configurable:** Configurable enhancement that can be toggled by the administrator.
- **[R] Recommended:** Best-practice architectural or UX capability vital for scalability.
- **[OOS] Out-of-Scope:** Explicitly deferred features (e.g., full native mobile app store deployment, hardware IoT smart meter direct telemetry, multi-tenant SaaS billing).

## 4. Verification of Out-Of-Scope Exclusions
The following features are formally classified as **[OOS] Out-of-Scope** and MUST NOT be built as mandatory components during core delivery:
1. Native Mobile App Store (iOS/Android IPA/APK) distribution — Replaced by fully responsive Mobile-First Web Application (PWA ready).
2. Live Inverter IoT Hardware Direct Telemetry / MQTT streaming — Inverters at SunPower Solutions are inspected via manual readings and error codes entered by customer/technician.
3. Multi-Tenant SaaS Subscriptions — Platform is purpose-built as single-tenant enterprise ERP for SunPower Solutions.
4. Autonomous Financial Action by AI — AI is strictly advisory; automated payouts, refunds, and ticket closures are blocked.
5. Third-party statutory payroll filing integrations (e.g., automated PF/ESI government filing) — Replaced by timesheet tracking and internal payout export.
